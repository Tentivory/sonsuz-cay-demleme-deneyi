# 🍵 Sonsuz Çay Demleme Deneyi

## Dünyanın En Ciddi, En Bilimsel ve En Gereksiz Çay Demleme Simülasyonu

Bu repository, insanlık tarihinin en büyük sorularından birine cevap arar:

**"Bir çay ne kadar süre demlenirse yeterince demlenmiş olur?"**

Cevap: **Asla.**

### 📊 Bilimsel Temeller

- Termodinamik yasaları göz ardı edilmiştir (bilerek).
- Çay yapraklarının psikolojik durumu göz önünde bulundurulmuştur.
- Şekerin erime hızı, kuantum belirsizlik ilkesi ile açıklanmıştır.
- Deney sonsuza kadar devam eder çünkü "bitmiş çay" diye bir kavram yoktur.

### 🚀 Nasıl Çalıştırılır?

```bash
python cay_demle.py
```

Program başlar, çay demlenmeye başlar, şikayet eder, demlenmeye devam eder. Durdurursanız çay küsülür.

### 🎯 Özellikler

- Sonsuz demlenme süresi
- Rastgele bilimsel şikayetler
- 7'nin katlarında "başarı" mesajları (hiçbir şey başarmadınız)
- Gerçek çay içme ihtiyacını %340 artırma garantisi
- Ctrl+C ile küsme mekanizması

### 📝 Katkıda Bulunma

Katkıda bulunmak istiyorsanız, lütfen kendi çay demleme teorilerinizi pull request olarak gönderin. Onaylanmayacaktır ama gönderin.

### ⚠️ Uyarılar

- Bu program gerçek çay demlemez.
- Gerçek çay demlemek için su kaynatın, çay koyun, bekleyin. (devrim niteliğinde bilgi)
- Program çalışırken gerçek çay içerseniz, simülasyon kıskanabilir.

### 🏼 Lisans

Bu proje MIT lisansı altındadır. Yani çay demleyebilirsiniz, demlemeyebilirsiniz, kimse sormaz.
